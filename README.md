# KoloCubik website

Official public product, support and privacy pages: https://victorshev1989-lab.github.io/KoloCubik-site/

This repository contains static website files and approved public media only. The iOS application source is stored in a separate private repository.

Hosting: GitHub Pages, main branch, root folder. No build tooling or dependencies. Open index.html locally or serve with python3 -m http.server. Pages use system fonts and no external scripts, analytics, forms, or cookies added by the developer.

English: index.html, support.html, privacy.html. Russian: ru/index.html, ru/support.html, ru/privacy.html.

After App Store publication, add the actual apps.apple.com URL to the release section in both landing pages. Current status: preparing for release.
